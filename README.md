# Hangman Game

I made a hangman game which is very beginner friendly and works really good, using Python. It uses for loops, while loops and if statements to run the game logic, and the player has 5 lives to guess the word.

## How to run
```
python3 hangman.py
```

## What it can do
- Makes sure the same letter is never guessed twice
- Makes sure the whole word can't be guessed instead of a single letter
- Notifies the user when they guess a correct letter, and also when they guess wrong
- Tells the player at the end whether they won or lost
