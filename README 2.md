# Basic Chatbot

A simple chatbot that replies to basic messages.

## How to run
```
python3 chatbot.py
```

## What it understands
- hello
- how are you
- bye

Type "bye" to end the conversation. If you type something it doesn't recognize, it'll let you know it didn't understand.

## What I'd add with more time
Recognize more phrases and handle slightly different wordings, not just exact matches.
